# Evaluation

Separate numerical software correctness from research quality. Numerical tests must cover independent expected proceeds and P&L, exact breach boundaries, monotonicity, missing data, partial fills, timestamp mismatches, instrument/currency mismatches and deterministic results.

Initial corpus is developer-inspected calibration material, not an untouched holdout. NVIDIA FY25 Q2 GAAP gross margin (75.1%) and FY25 Q3 (74.6%) can illustrate a confirmed 75% floor being breached. Revenue growth can remain supported despite the margin decline: this is the negative control. Scenarios for position price and book liquidity are synthetic and labeled separately.

Replay gates documents by conservative availability time before classification. Model pretraining can still contain future facts; filtering does not remove that risk. The local rules-based replay is not evidence of LLM research quality. Publish denominators, misses, false alarms, exclusions and inspected cases.

The first frozen live calibration batch is complete; see [batch 01](evaluations/2026-09-11-batch-01/REPORT.md). It found strong raw passage classification on the small constructed set but only 1/21 full application-contract passes. The post-fix [v2 validation holdout](evaluations/2026-09-11-v2-validation-01/REPORT.md) then passed 5/5 complete application contracts with five first-attempt responses. A genuinely untouched independent benchmark, broader source cases and the fixed-shock calculation baseline remain pending, so no general AI-quality score is reported.

After batch 01, prompt versions v2 were implemented without live calls. The Bitget request now repeats the full schema in model-visible input, decoded arrays/scalars receive the one bounded repair, incomplete responses expose only an allowlisted reason, and the Bitget output allowance is 5,000 tokens. Regression fixtures reproduce the observed bare-array and output-limit shapes. The separate frozen v2 run validated these changes on five newly constructed cases; batch 01 remains an immutable record of v1 behavior and is not reinterpreted as v2 evidence.
