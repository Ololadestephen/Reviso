# Architecture

React + TypeScript + Vite in apps/web calls a local Python 3.12 FastAPI application in backend. Pydantic validates all user input. Decimal values cross HTTP as strings. SQLite stores immutable thesis versions and assessments, using a numbered migration and a repository transaction boundary. Local data is ignored by Git.

The explicit instrument registry permits three long research targets: Bitget rNVDA/USDT (`RNVDAUSDT`), rAAPL/USDT (`RAAPLUSDT`) and rMSFT/USDT (`RMSFTUSDT`). Every cache, market response, evidence record, assessment and AI context is bound to the selected identity. NVIDIA's primary historical company evidence can be replayed to test assumptions; this is not a historical backtest of a token that was not then listed, and that replay is not offered as Apple or Microsoft history. Position prices and order books in replay are explicitly controlled examples, not historical quotes. The original Ondo probe failed runtime coverage; its development-only database remains separate and is not migrated into rNVDA records.

Engines accept validated numerical inputs and never call an LLM. Services evaluate confirmed rules, gate evidence, build assessment hashes and compare versions. Providers return provenance plus explicit availability. Live Bitget public market data is a separate observation from replay. An LLM adapter must validate schema, bound repairs and cite passages; missing credentials must not enable a fake AI mode.

`backend/llm.py` defines the provider-neutral language-model protocol and a shared schema-validation layer. The preferred adapter calls the organizer's fixed OpenAI Responses-compatible endpoint with Qwen 3.8 Max and `BITGET_QWEN_API_KEY`; a fixed Groq Chat Completions adapter with Qwen 3.8 27B remains fallback. Bitget is selected whenever both keys exist. The Bitget adapter has a 90-second read window and 5,000-token output allowance based on observed latency/reasoning usage; Groq retains its existing limits. Because the proxy did not enforce `text.format` during batch 01, prompt versions v2 repeat the exact JSON Schema in the model-visible input. Decoded JSON with the wrong root type reaches local validation and its single repair opportunity. Incomplete responses disclose only an allowlisted reason. Pydantic validation remains authoritative. User text and allowlisted evidence are data; no model-selected URL or tool execution is supported. HTTP failures fail closed without automatic paid retries.

Thesis extraction and newcomer assumption suggestion return unsaved, editable proposals. They cannot confirm or create a thesis. Narrative review accepts only the selected assessment's allowlisted passages, must cover every confirmed assumption exactly once, and can cite only supplied evidence IDs. Cited follow-up answers fetch the exact saved thesis/assessment/evidence context server-side, reject foreign evidence IDs, and persist by a hash of the context, question, provider, model and prompt. Old answers remain attached to their original context. These AI outputs record provider, model, prompt version and time and cannot modify deterministic results, thesis versions or decisions. Identical inputs reuse saved output before another provider call.

Local single-user API binds to loopback and uses an explicit local identity. Public demo requires Google sign-in; production never falls back to the local identity if Google is missing. Research rows are scoped by internal `owner_id`. Login methods are stored separately and are not merged by email. Before a later host change, keep a persistent disk, per-user authorization and retention. No arbitrary URL fetching, file upload or trading routes are exposed.

The repository uses optimistic version checks with SQLite write transactions. Revision, decision event and derived reassessment are committed together. Assessments remain immutable and idempotent by input hash; a separate selected-assessment pointer supports replay rewind without duplicating results or deleting future history. Revision citations must belong to the selected evidence set, not merely any previously viewed document. Migration 002 backfills the selection for older local records.

The bridge invokes only the official SDK's read-only public market module with one server-validated registry ID and a fixed endpoint. It runs as a fixed argument array with a resolved Node executable, minimal environment, timeout and per-instrument cache. Provider normalization checks the selected stock identity, base/quote currency, online status, finite values and source freshness before exposing data.

Public company retrieval is composed in `backend/company_disclosures.py`. NVIDIA newsroom retrieval and HTML extraction live in `backend/disclosures.py` and `backend/disclosure_parser.py`; Apple/Microsoft and NVIDIA recovery use exact CIK-bound SEC company-facts URLs through `backend/sec_companyfacts.py`. The fixed NVIDIA listing discovers the newest supported earnings-release path. SEC parsing selects aligned quarterly USD duration facts and derives year-over-year revenue growth and GAAP gross margin only from matching contexts. CIK/name mismatches and unknown layouts fail closed. NVIDIA's SEC path is labeled retrieval redundancy, not corroboration. Evidence carries explicit instrument identity, public/curated origin, parser version, publication/availability/period/retrieval timestamps and excerpt/document hashes.

Public evidence is embedded in immutable SQLite assessments. Source lookup for private excerpts is limited to assessments owned by the signed-in user and does not refetch the network. Bundled NVIDIA replay documents remain a public catalog. AI review, follow-up questions, numerical stress and revisions use the selected saved evidence; only an explicit refresh discovers a new current document. The curated historical replay remains fixed. Refresh retrieval status and warnings persist through stress and revision. Migration 003 adds immutable, assessment-bound research answers. Markdown/JSON export assembles only repository state through the requested thesis version and never refetches or calls an LLM. No full-document archive or arbitrary source feed is implemented.
